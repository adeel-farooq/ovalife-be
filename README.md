# ovalife-node

Express boilerplate created in the `ovalife-node` folder (root of workspace).

How to run:

```bash
cd "C:\\Users\\adeel\\Documents\\MrRetailer\\ovalife-node"
npm install
npm run dev   # requires nodemon (dev)
# or
npm start
```

Endpoints:

- GET / -> health
- GET /api/hello -> sample API
